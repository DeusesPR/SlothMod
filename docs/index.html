Quick Answers

Is SlothMod really free — and do I own the mods I make?

Yes. SlothMod is free to download and use, and every mod you build belongs to you. Share, publish, or monetize your mods freely on Modrinth or wherever you share mods under the SlothMod Free Use Terms.

Do I need to know how to code or pay for AI?

No. All six visual studios (World Sculptor, Build Studio, Whole-Game Studio, Brain & Colonies, 3D Sculpt/Paint/FX, and Visual Blueprints) work 100% offline at $0 AI cost. If you want AI help, you can use free tiers, local models via LM Studio / Ollama, or your own API key with spending caps — and coders can open the built-in Java editor anytime.

Why does Windows show a blue SmartScreen warning?

Because SlothMod is free and not paid-signed yet, Windows SmartScreen can show "Windows protected your PC" on first download. Click More info, then Run anyway. Only run installers downloaded directly from slothmod.com or GitHub Releases.

How does SlothMod keep my PC and worlds safe?

AI changes happen in a sandbox copy with version History and one-click Undo, and AI-written code is scanned before every build. Imported .mca worlds are never overwritten in place — SlothMod always exports a clean copy.

Which Minecraft versions and mod loaders are supported?

Minecraft 26.3 (Fabric & NeoForge, flagship), 1.21.1 (Fabric & NeoForge), and 1.20.1 (Fabric & Forge). Existing 26.1 and 26.2 projects upgrade to 26.3 in one click.

What about privacy, accounts, and my API keys?

No accounts, no cookies and no tracking. API keys are stored in Windows Credential Manager, your Microsoft account stays in the official Minecraft launcher, and prompts go only to the AI provider you pick.

Does it work on Mac or Linux, or how do I report a bug?

SlothMod currently runs on 64-bit Windows 10 and 11. If anything goes wrong, click Report a problem inside the app (keys and PC usernames are stripped automatically) or open an issue on GitHub.
